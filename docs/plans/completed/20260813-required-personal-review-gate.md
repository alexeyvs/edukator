# Обязательный персональный разбор в дневном гейте

## Summary

- Компьютер разблокируется после двух независимых условий: завершены 3 обычных забега и получен зачёт 4/5 по обязательному персональному разбору.
- Обязательным становится только первый предложенный материал; остальные остаются добровольными.
- Материал, опубликованный после третьего забега, не переблокирует компьютер сегодня, но становится обязательным на следующие московские сутки.
- После незачёта ученик снова читает ту же теорию и повторяет тот же тест до зачёта.

- [x] Поднять версию SQLite-схемы и добавить `ready_at`, повторяемые связи материала с `lesson-run` и признак попытки, не влияющей на прогресс.
- [x] Мигрировать существующие материалы, связи запусков и попытки без превращения исторических завершённых неуспешных материалов в новые обязательства.
- [x] Добавить или обновить тесты миграции базы предыдущей версии.

### Task 2: Составное состояние дневного гейта

- [x] Выбирать первый обязательный материал по `ready_at`, затем `id`, с отсечкой по завершению третьего забега и московским суткам.
- [x] Обеспечить идентичный результат `/api/run/plan` и `/api/gate/status`, обновить валидацию Family Safety Controller.

### Task 3: Повторное прохождение обязательного разбора

- [x] Сохранять все предыдущие запуски и ответы, поддержать возобновление текущего незавершённого запуска и идемпотентный финиш.

## Assumptions

- «Первый» означает самое раннее опубликованное предложение, а не материал с наибольшим текущим приоритетом.
- Если обязательный материал автоматически снят как потерявший актуальность до прохождения, требование считается отменённым; следующий материал не подменяет его в тот же день.
- Повтор использует неизменные теорию и пять вопросов, но хранится как отдельный запуск.
